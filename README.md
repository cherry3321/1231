# NovaMSG — Мессенджер на Python

## Установка и запуск

### 1. Создайте виртуальное окружение (рекомендуется)
```bash
python -m venv venv
source venv/bin/activate     # Linux/Mac
venv\Scripts\activate        # Windows
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Запустите сервер
```bash
python app.py
```

### 4. Откройте в браузере
```
http://localhost:5050
```

---

## Функции

- **Аккаунты**: Регистрация, вход, выход
- **Личные чаты**: Поиск пользователей, создание диалогов
- **Группы**: Создание групп с несколькими участниками
- **Сообщения**: Текст в реальном времени через WebSocket
- **Файлы**: Отправка любых файлов (до 50MB)
- **Изображения**: Автоматическое превью и лайтбокс
- **Индикатор печати**: Показывает когда собеседник печатает
- **Непрочитанные**: Счётчик непрочитанных сообщений
- **Настройки**: Изменение имени, биографии, цвета аватара, пароля
- **Статус**: Онлайн/офлайн индикаторы

## Технологии

- **Backend**: Python, Flask, Flask-SocketIO, SQLAlchemy (SQLite)
- **Frontend**: HTML5, CSS3, JavaScript (без фреймворков)
- **WebSocket**: Socket.IO для сообщений в реальном времени
